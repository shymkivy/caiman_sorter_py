====================================================
 CaImAn Sorter (Python) v1.03 — Installation & Usage
====================================================

A PyQt5 GUI for sorting/curating CaImAn CNMF outputs. Python port of
the MATLAB caiman_sorter pipeline:
  https://github.com/shymkivy/caiman_sorter


REQUIREMENTS
------------
- Python 3.9 or later (Anaconda/Miniconda recommended)
- The Python packages in requirements.txt: PyQt5, matplotlib, numpy,
  scipy, h5py, scikit-image, scikit-learn, hdf5storage, joblib.
  (scikit-learn is only used by the NMF merge method;
   hdf5storage is only used for MATLAB v7.3 .mat export/import.)
- CaImAn Python -- ONLY needed for constrained-foopsi deconvolution.
  Everything else (loading, sorting, evaluation, merging, smooth dF/dt
  deconvolution, save/.mat export) runs without it.


INSTALLATION
------------
CaImAn is the only heavyweight dependency and is not cleanly
pip-installable, so there are two ways to set up. Either works.

Run the "pip install" step from inside the caiman_sorter_py folder
(where requirements.txt lives), or pass the full path to it.

Option A -- reuse your existing "caiman" env (full functionality)
  If you already have the conda env that ships with CaImAn, just add
  this app's extra packages to it:

     conda activate caiman
     pip install -r requirements.txt

  This gives you everything, including constrained-foopsi deconvolution.

Option B -- make a fresh, lightweight env (no CaImAn)
  Creates a minimal env. You get the whole app EXCEPT constrained-foopsi
  deconvolution -- smooth dF/dt still works.

     conda create -n caiman_sorter python=3.11
     conda activate caiman_sorter
     pip install -r requirements.txt


DOWNLOAD
--------
The app runs as a Python module named "caiman_sorter_py", so the
folder MUST be named exactly "caiman_sorter_py". The easiest way to
get that is with git:

     git clone https://github.com/shymkivy/caiman_sorter_py

This creates a folder named "caiman_sorter_py" (correct name, and you
can update later with "git pull").

No git? Use GitHub's "Code > Download ZIP" instead -- but the ZIP
unpacks to a folder named "caiman_sorter_py-master". RENAME it to
"caiman_sorter_py" before running, or the command below won't find it.


RUNNING THE GUI
---------------
Run from the directory that CONTAINS the caiman_sorter_py folder
(its parent), NOT from inside it:

     cd path/to/parent          (the folder that holds caiman_sorter_py)
     python -m caiman_sorter_py

For example, if you cloned into  ~/code  (so that
~/code/caiman_sorter_py exists), then  cd ~/code  and run the command.

The window title shows the version (e.g. "CaImAn Sorter v1.03").


SUPPORTED FILE FORMATS
----------------------
The Load button auto-detects the file type by looking at HDF5 root
attributes / group layout, not the extension:

  CaImAn HDF5 output (*.hdf5, *.h5)
      Raw CNMF results. Loads est + runs full proc init
      (noise, peaks, AR coefficients, firing stability) — typically
      5–30 s for a few hundred cells.

  Sort session (*.h5)
      A previously-saved full session. Restores est/proc/ops directly,
      no proc init needed (fast).

  Sort session (*.mat)
      MATLAB v7.3 format — the same layout the legacy MATLAB pipeline
      produces (f_cs_save_data.m), or what this app exports when
      "Also save MATLAB .mat" is on.

  Ops file (*_ops.h5)
      Only the GUI parameters. Loading one applies the parameters in
      place without touching est/proc — useful for sharing thresholds
      and deconvolution settings between recordings.


WORKFLOW
--------
1. Browse → pick a CaImAn HDF5 (or an existing sort session).
2. Load → est/proc populate; the image panel shows accepted/rejected
   composites with contours, and the trace panel shows the current cell.
3. Inspect cells:
   • Click a contour to jump to that cell.
   • Right-click a contour to toggle accept/reject (manual override).
   • Up/Down or the spinner in the Component box steps through cells.
4. Tune evaluation thresholds in the Params tab (two modes:
   CaImAn-style union/intersection or stepwise reject-threshold).
5. Run deconvolution in the Deconvolution tab:
   • Smooth dF/dt — Gaussian-smoothed temporal derivative
     (fast, vectorised; live preview updates as you change params).
   • Constrained foopsi (OASIS / CVXPY / CVX) — parallelised across
     cells with joblib. Solver availability is checked at run time
     and a friendly install hint is shown if the picked backend is
     missing.
6. Find duplicates in the Merge tab:
   • Spatial overlap (A^T A) + temporal correlation thresholds.
   • Per-pair "Plot pair" preview shows both cells and the merge
     candidate side-by-side; the trace plot has Pan/Zoom toolbar.
   • Apply either "choose best SNR" (reject the lower-SNR² cell) or
     "create new cell" with one of four merge methods (weighted ave,
     full mean corr, svd, nmf) — full proc metrics + foopsi are
     recomputed for the new cell.
7. Save:
   • Save → writes the full session as <stem><save_tag>.h5
   • If "Also save MATLAB .mat" is on, a sidecar <stem><save_tag>.mat
     is written too, matching the MATLAB pipeline's format.
   • Save Ops → writes <stem><save_tag>_ops.h5 with just the parameters.


FILE STRUCTURE
--------------
caiman_sorter_py/
  __init__.py            __version__ (single source of truth)
  __main__.py            entry point (python -m caiman_sorter_py)
  app.py                 QApplication bootstrap
  CLAUDE.md              architecture notes for Claude Code
  INSTRUCTIONS.txt       this file
  io/
    hdf5_loader.py       load CaImAn .hdf5 output
    session.py           save/load .h5 / _ops.h5 (self-contained)
    mat_export.py        write MATLAB v7.3 .mat (legacy compat)
    mat_loader.py        read MATLAB v7.3 .mat back into est/proc/ops
  core/
    state.py             Estimates / Proc / Ops dataclasses + Session
    proc_init.py         noise, AR coefficients, peaks, firing stab
    evaluation.py        accept/reject logic (caiman / reject-threshold)
    deconvolution.py     smooth dF/dt, OASIS/CVXPY/CVX foopsi
    merge.py             duplicate detection + cell merging
    contours.py          contour extraction from sparse A
  ui/
    main_window.py       toolbar, dialogs (load/save/foopsi), menus
    image_panel.py       accepted/rejected composite images + contours
    trace_panel.py       calcium trace plot with deconv overlays
    nav_panel.py         cell navigation, metrics, component image
    params_panel.py      Evaluation + Deconvolution + Save parameters
    merge_panel.py       duplicate-detection table + plot dialog


SAVED FILE LAYOUT
-----------------
Both .h5 file types carry HDF5 root attributes:
  format       — "caiman_sorter_session" or "caiman_sorter_ops"
  app_version  — e.g. "1.03"
  saved_at     — ISO timestamp

Full sessions also store the source CaImAn path under source_path.
